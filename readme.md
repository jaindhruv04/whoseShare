# WhoseShare

A cross-platform expense-sharing application that helps friends manage shared expenses, track debts, and simplify settlements.

## Tech Stack

- Frontend: React + Vite
- Mobile: React Native + Expo
- Backend: Node.js + Express
- Database: PostgreSQL + Prisma
- Algorithms: Greedy Debt Simplification and Bitmask Dynamic Programming

## Project Status

🚧 Under Development

## Planned Features

- User authentication
- Group expense management
- Equal, exact, and percentage-based expense splitting
- Expense history and balance tracking
- Automated debt simplification
- Cross-platform support for web and mobile
